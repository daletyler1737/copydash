安装程序退出代码说明

Setup exit codes — 妙复制大师 / CopyDash  ·  安装程序 Setup 1.0.1

本页说明「妙复制大师 CopyDash」Windows 安装程序（妙复制大师-CopyDash-Setup.exe） 在退出时可能返回的全部代码。安装程序不带命令行界面，支持静默安装 /S，安装到当前用户目录（%LOCALAPPDATA%\Programs\CopyDash）， 不需要管理员权限、不写系统目录、不写 HKLM、不联网、不需要重启。

返回代码表

返回值含义
0 安装成功。文件已就位、注册表项（HKCU\Software\CopyDash）、开始菜单快捷方式与卸载程序均已创建。
Success — the application was installed completely.
1602 用户已取消安装（ERROR_INSTALL_USEREXIT）。用户在向导中点击「取消」，并在确认对话框中选择「是」，安装被中止且未做任何更改。
User cancelled the installation; nothing was changed.
1603 安装失败（ERROR_INSTALL_FAILURE）。发生在下列情况：① 妙复制大师本体仍在运行，占用着待替换的程序文件；② 无法写入安装目录（无写权限、磁盘空间不足或磁盘不可写）。
Fatal error during installation — the app is running and its files are locked, or the target folder could not be written (no permission / disk full).

关于其他数值

  • 本安装程序只主动返回上表三种代码。
  • 若收到上表以外的退出代码，说明进程在安装程序自身逻辑开始之前就被系统拦下或终止（例如 AppLocker / 组策略 / 安全软件禁止运行、被手动结束进程）。这类代码由 Windows 产生，不是安装程序设置的。常见示例：5 拒绝访问、2 找不到文件、1 进程被中止。
  • 安装程序不检测、也不返回「需要重启」「网络故障」「应用程序已存在」等代码：它不联网、不注册系统服务、不需要重启；已经装过的情况下会原地覆盖升级并返回 0。
  • 遇到 1603 时：先退出正在运行的妙复制大师（任务栏图标 → 右键退出），确认磁盘有几十 MB 空闲，然后重跑安装程序即可。

English summary

Exit codeMeaning
0Installation succeeded.
1602User cancelled; nothing was changed.
1603Fatal error: the app is still running (locked files) or the install folder is not writable.

Only the three codes above are returned by the installer itself. Any other value comes from Windows (blocked by policy/security software, or the process was terminated before setup logic ran). The installer never needs a reboot, does not use the network, and upgrades in place — so no "reboot required", "network failure" or "already installed" codes are ever returned. Silent install: /S.
