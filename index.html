妙复制大师 · CopyDash

Windows 高速复制 / 移动工具 · Windows high-speed copy & move tool

一个 EXE，两套复制引擎。窗口左右两栏摆好源与目标，一键开始；也可以在资源管理器里右键任意文件或文件夹，选「复制到…」或「移动到…」。

One EXE, two copy engines. Put source and destination in the two panes and go — or right-click any file or folder in Explorer and pick “Copy to…” / “Move to…”.

功能 / Features

  • 双引擎可切换：柔博引擎（RoboEngine） 适合海量小文件、长路径、需要重试的活儿；原生引擎（CNMEngine） 适合大文件与本地快速搬运。
  • 右键菜单集成：「复制到…／移动到…」，免管理员权限（只写当前用户注册表）。
  • 复制后校验（哈希比对）、进度与速度显示、失败项明细与重试。
  • 中英双语界面、深浅色可切换、免安装单文件版与标准安装包两种形态。

Two switchable engines · Explorer context menu · verify-after-copy (hash compare) · live progress & speed · failure list with retry · Chinese/English UI · light & dark theme · portable single EXE or standard installer.

安装 / Installation

  1. 从 Microsoft Store 安装（上架后此处会给出商店链接）；或使用标准安装包 妙复制大师-CopyDash-Setup.exe，一路「下一步」即可。
  2. 想免安装：直接用便携版 CopyDash.exe，双击就能跑。
  3. 右键菜单在首次运行后自动注册；不需要时可在软件内的设置里关闭，或直接卸载。

常见问题 / FAQ

复制到一半失败怎么办？ / A copy failed halfway — what now?

窗口下方会列出失败的文件和原因，点「重试」即可继续。长路径、被占用的文件、权限不足是最常见的三种原因；「柔博引擎」对这三类情况的处理更稳。

卸载后右键菜单还在吗？ / Do the context-menu entries stay after uninstall?

卸载会一并清掉右键菜单、快捷方式和偏好设置，不残留。若你用的是便携版（绿色版），右键菜单可在软件内关闭后再删除文件夹。

会上传我的文件或使用数据吗？ / Does it upload my files or usage data?

不会。本软件完全离线，没有任何联网代码、统计或广告组件。详见 隐私策略 / Privacy Policy。
